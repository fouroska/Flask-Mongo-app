# Flask Application with MongoDB

Αυτό το project είναι μια εφαρμογή Flask που συνδέεται με μια βάση δεδομένων MongoDB και παρέχει διάφορες δυνατότητες χρήστη,
όπως δημιουργία χρήστη, login, και διαχείριση φοιτητών.

## Τι είναι αυτό;

Η εφαρμογή είναι βασισμένη στο Flask και επιτρέπει στον χρήστη να δημιουργήσει έναν λογαριασμό, να συνδεθεί, να προσθέσει φοιτητές και
να εκτελέσει διάφορες άλλες ενέργειες με την MongoDB.

## Εξαρτήσεις

Για να τρέξει η εφαρμογή τοπικά, πρέπει να έχετε εγκατεστημένα τα εξής:

- Python 3.9.13
- Flask
- MongoDB (pymongo)
- Postman (για δοκιμή API)
  
## Testing

- Χρησιμοποιήστε το αρχείο Final_Flask_Mongo.postman_collection.json για να εισάγετε τα έτοιμα requests στο Postman.
